## File insights (detail)

Facts from [#73](https://github.com/zohaib089/structura/pull/73), [#74](https://github.com/zohaib089/structura/pull/74), [#75](https://github.com/zohaib089/structura/pull/75), [#77](https://github.com/zohaib089/structura/pull/77), [#79](https://github.com/zohaib089/structura/pull/79) and the docs on `main`:

- Schema minor bump to **1.1.0**. Readers of 1.0.0 still work; 1.0.0 readers of 1.1.0 strip unknown fields and keep `calls` as a generic edge.
- **`calls` edges:** same-file static calls are `EXTRACTED`; cross-file calls resolved through imports inherit that import’s provenance; unresolved/dynamic calls make no edge and are counted only in optional `coverage.calls`.
- **Symbol / state fields:** optional `scope`, `mutable`, `stateKind`, `parent`, `paramCount`, plus optional sanitised `docSummary` on symbols and files.
- **`docSummary`:** off by default; CLI opt-in with `--doc-summaries`. Hardened sanitiser (NFKC, zero-width strip, secret detection including AWS / GitLab / base64 / credential prose). Mid-token truncation drops the field. API / workspace scans never persist `docSummary` on the graph.
- **Hosted first-comment summaries (#79):** scan-worker `fileSummaries` go through the same `sanitizeDocSummary`; rejected text becomes `null`. Engine re-exports the sanitiser (no fork).
- **UI:** step 1 lists definitions; step 2 shows functions, Calls / Called by, and State. Panel-fit keeps the graph clear of the open panel.
