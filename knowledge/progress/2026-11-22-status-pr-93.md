## Details

- **API:** `POST /api/workspaces/:workspaceId/transfer-ownership` with body `{ memberId, stayAsAdmin }`. Only an owner can call it. It runs in one transaction: the target member is promoted to owner, then the caller becomes an admin or is removed. This keeps the rule that a workspace always has an owner. Errors: 401 (not signed in), 400 (bad body), 403 (caller is not an owner), 404 (workspace or member not found).
- **Members page:** choosing Owner opens a confirm dialog with a "Stay on as an admin" option.
- **Behaviour change:** Owner in the role menu now transfers ownership instead of adding a co-owner. `PATCH` can still create co-owners.
- **Tests:** API member routes 19 (5 new), Members unit 10.
