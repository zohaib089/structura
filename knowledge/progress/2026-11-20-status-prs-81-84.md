## VS Code extension smoke test

Source: the smoke notes and result files kept locally in `/workspace/graph-visual/ext-smoke/` (not in the repo).

- **Setup:** VS Code 1.147.0 stable under Xvfb, driven by Playwright. The private `atlasmith-0.1.0.vsix` was installed with `code --install-extension` and run on a real scan of this repo.
- **Activation:** opened from the editor-title icon. The extension host log shows no errors or warnings.
- **Consent:** asks before scanning: "Scan this project with Atlasmith? It runs only on this computer."
- **Scan time:** 596 ms (dark run) and 857 ms (light run).
- **Graph:** file view renders radial in a split editor (541px) and full width (1382px). Radial hover highlights the path; Linear hover did not change any highlight. Linear view and the file panel work.
- **File insights:** the Functions list showed 14 function cards with Calls data for `apps/web/src/viewer/file-neighborhood.ts`.
- **Found and fixed in #84:**
  - A symbol jump hid the graph tab. After the fix, the file opens at the right line (line 35) beside the graph, with both editor groups visible.
  - The graph did not pick up edits. After the fix, the variable count went from 4 to 5 after an edit.
- Both themes (dark and light) were captured.

## Open gaps

- Gaps found in the smoke test and not fixed in #84 (being worked on locally as of 2026-11-21):
  - The project graph in Linear view shows a single `dir:.` node, because the file graph's Linear choice carries over.
  - No rescan button while a graph is open, and the open panel does not refresh after an edit.
  - VS Code theme changes are not sent to an open graph.
  - At a 1024px window, the default side-by-side split leaves the graph about 220px wide (phone layout), hiding the filters and Back buttons.
  - Linear-view hover does not highlight the path.
  - The zoom pad Fit after zoom-outs did not register in the test; not yet confirmed as a bug.
  - Duplicate warnings and change-impact alerts are not in the extension. Impact analysis exists only in the engine (`graph/impact.ts`) and the CLI's MCP `impact_lite` tool.
- The first smoke pass in each theme ended early when the test window closed, so the second-pass results files are empty. The after-fix check was run in dark theme only.
- Still open from #70: Marketplace and Open VSX publisher registration, and any public publish. Both need zohaib's approval.
