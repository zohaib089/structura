# Decision 002: Frontend Stack

Date: Day 1
Project: Structura

We chose the following for the frontend:

- **Vue 3** + TypeScript
- **Pinia** → for state management
- **Vue Router** → for navigation
- **Vue Flow** → for architecture graph
- **CSS Variables** → for Light/Dark theme (Design System)
- **consola** → for clean logging

### Why these choices?

- Official and well-supported libraries
- Easy to maintain
- Good performance
- Ready for future growth (agents, complex UI, etc.)

This stack is modern and suitable for a professional architecture tool.
